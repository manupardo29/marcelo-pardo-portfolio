# Imágenes de obras

Colocar aquí las fotos de cada proyecto. Usar los nombres sugeridos en `src/data/projects.js`.

| Archivo sugerido | Obra |
|------------------|------|
| `mercado-libre.jpg` | Red de agua — Mercado Libre |
| `polo-pilar.jpg` | Polo Industrial Pilar |
| `aeropuerto-san-fernando.jpg` | Aeropuerto de San Fernando |
| `arroyo-vega.jpg` | Cámara de enlace — Arroyo Vega |
| `cuenca-cildaniz.jpg` | Cuenca Cildañez |
| `arroyo-maldonado.jpg` | Arroyo Maldonado |
| `avenida-lugones.jpg` | Avenida Lugones |
| `villa-gesell.jpg` | Acceso Sur — Villa Gesell |
| `rn-237-crema.jpg` | RN 237 y RN 40 — CREMA |
| `zvartnots.jpg` | Aeropuerto Zvartnots |
| `perales-aguiar.jpg` | Pavimento urbano — Conurbano |

Luego actualizar `image` en `src/data/projects.js`:

```js
image: '/projects/mercado-libre.jpg',
```

Formatos recomendados: JPG o WebP. Tamaño orientativo: 1200–1600 px de ancho.
